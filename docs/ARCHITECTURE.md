# Architecture and implementation decisions

- Next.js App Router, React, strict TypeScript and Tailwind CSS v4. Original CSS design system follows #2869F0 / #142033 / #EAF2FF / #F8FAFD. Lucide icons and code-native original Hanzi illustration; no scraped branding, lessons or audio. Extra state/query/animation libraries were omitted because the current UI does not require them.
- Auth.js v5 credentials with JWT sessions. Passwords and users are persisted through Prisma. Every protected action reloads the current user and role from the database; account deletion immediately makes a retained JWT unusable. Account/Session schema models allow future providers/database sessions but are not used by the current credentials JWT mode.
- Forty relational models cover the specified content, attempt, review, activity, conversation, writing, gamification, media, revision and audit concepts, plus RateLimit. Referential integrity and cascades handle owned data. Audit actor deletion anonymizes the relation.
- PostgreSQL is the primary schema. Equivalent SQLite schema/migrations support zero-service local verification. Prisma 6.19 is pinned; no unofficial database adapter is required. Serializable transactions retry conflicts, unique keys enforce XP/attempt/review identity, and due snapshots prevent stale ratings.
- Immutable LessonVersion snapshots contain grading data. The authenticated student response excludes answer/alternate/explanation fields until an attempt is evaluated. Public learning materials and hints are educational aids; this is not high-stakes exam anti-cheat. Vocabulary and grammar are shared library records; CMS edits to those libraries update displayed reference material, while past exercise grading remains frozen in the lesson version.
- API modules centralize Zod validation, origin checks, roles, ownership, pagination and errors. A catchall API route is explicit application routing, not a mock backend. Client UI uses typed fetch responses and server-computed statistics. No localStorage score/XP source exists.
- UI is mobile-first with adaptive desktop sidebar and five-item mobile navigation. System Chinese fonts avoid external font downloads. Focus outlines, text labels, skip link, reduced-motion handling, semantic inputs and dark theme are included. Writing requires a pointer; accessible stroke-sequence text provides a study alternative. Full screen-reader/assistive-technology audit remains necessary.
- TutorProvider and OpenAICompatibleTutor are server-only imports. Provider failures never produce pretend feedback. The declared specialized pronunciation, email, push and billing capabilities remain false. TTS is device speech synthesis and varies with installed voices.
- PWA service worker caches the offline page, manifest/icons, and static assets. It avoids API/private page caching. Vocabulary is deliberately saved for self-practice. There is no background progress queue; all scored mutations require connectivity and server confirmation.

Delivery scope follows the specification's permission to prioritize functioning subsets. Source, migrations, content, setup, local tests, browser evidence and backlog are delivered together. A successful build is not a production-readiness claim.
